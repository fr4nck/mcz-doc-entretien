# Menus et codes d'accès MCZ Maestro

[Retour à l'accueil](../README.md)

Fiche documentaire du **8 novembre 2026**, destinée à l'application **MCZ Maestro**. Le code produit est désormais relevé : `7117008A` (DOC Comfort Air) ; sa version logicielle reste à relever. La notice DOC 9 M1 citée pour les recettes concerne une autre référence : l'applicabilité de `1234` à cet exemplaire demeure à confirmer. Les codes ci-dessous n'ont pas encore été confirmés par un essai sur cet appareil.

## Quel code pour quel menu ?

| Menu | Code | Provenance et portée |
| --- | --- | --- |
| Menu technique | `0434` — conserver le zéro initial | Code rapporté et confirmé par plusieurs utilisateurs de MCZ Maestro [S9]. Son fonctionnement reste à confirmer sur le DOC suivi. |
| Recettes | `1234` | Code publié dans la notice DOC M1, partie 2, page 34 [S7]. Il ouvre les recettes air et pellets. |

Les deux lignes correspondent à des accès distincts. Le code du menu Recettes ne constitue pas une confirmation du code du menu technique.

## Accéder au menu technique

La notice DOC M1 décrit le parcours suivant [S8] :

1. Ouvrir le menu de l'application avec l'icône à trois traits.
2. Faire défiler jusqu'à **Menu technique**.
3. Saisir le mot de passe puis valider avec **OK**.

Le code issu des témoignages est `0434` [S9]. La notice décrit la procédure, sans publier ce mot de passe, et réserve cet accès aux techniciens agréés [S8].

### Limite de compatibilité

Des confirmations existent sur des appareils Maestro d'autres modèles [S9]. Un témoignage de 2025 indique cependant que `0434` n'est plus accepté sur l'appareil de son auteur, sans préciser suffisamment sa version [S10]. Ce retour ne démontre ni une modification pour tous les modèles, ni une incompatibilité particulière du DOC.

Si le code est refusé, relever la référence du poêle, la version de l'application, les informations logicielles disponibles et le message affiché avant de rechercher une procédure adaptée.

## Accéder aux recettes

Dans la notice DOC M1 : **Configurations → Recettes → `1234`** [S7]. Les intitulés peuvent dépendre de la version de l'interface.

Avant de modifier un réglage, photographier sa valeur d'origine. Cette fiche documente les accès ; elle ne fournit pas de nouvelles valeurs de combustion ou de sécurité.
